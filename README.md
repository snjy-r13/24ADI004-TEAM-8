# Google Play Store Apps EDA

This project contains an exploratory data analysis (EDA) notebook on Google Play Store apps.

## Notebook
- `Playstore.ipynb`

## Dataset
Source (Kaggle):
- https://www.kaggle.com/datasets/gauthamp10/google-playstore-apps

Direct downloadable API link (requires Kaggle login/API setup):
- https://www.kaggle.com/api/v1/datasets/download/gauthamp10/google-playstore-apps

## Files in this project
- `Playstore.ipynb` → analysis notebook
- `Google-Playstore.csv` → dataset used in the notebook

## Analysis covered
- Data loading and preview
- Data types, summary statistics, missing values, and duplicates
- Data cleaning and feature formatting
- Outlier checks
- Univariate, bivariate, and multivariate visual analysis

## Python libraries used
- pandas
- numpy
- matplotlib
- seaborn

## How to run
1. Install dependencies:
   ```bash
   pip install pandas numpy matplotlib seaborn scipy jupyter
   ```
2. Open Jupyter Notebook:
   ```bash
   jupyter notebook
   ```
3. Open `Playstore.ipynb` and run cells sequentially.
